A program that writes one funny line of awkward robot small talk in an elevator to `/output/entry.txt`.

## The line

> So... do you come here often? I ask because I have been stuck between floors three and four since 2019.

## Run locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
